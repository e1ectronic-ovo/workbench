# Whaletide · Tide Deck 首页

> 本页规则覆盖 `../MASTER.md` 中的营销页、黑金配色与 Cormorant/Montserrat 规则。  
> 适用对象：Whaletide 桌面工作台首页与全局应用外壳。

## 定位

首页不是营销落地页，而是一个安静、可扫读的桌面工作台。  
视觉关键词：**潮汐、玻璃、留白、信息密度、克制动效**。

- 保留现有角色插画、主题皮肤与动态 `--accent`。
- 不引入滚动叙事、视差章节或营销 CTA。
- 不写死黑金配色，不在中文界面中使用 Cormorant/Montserrat。
- 所有图标使用一致的内联 SVG，不使用 Emoji。

## 页面骨架

1. **Sidebar**：品牌标记 + 鲸汐 / WHALETIDE；首页独立一级入口；应用与网站分组；底部偏好设置。
2. **Masthead**：时段问候、格式化日期、简短工作台说明、启用组件数量、可见的「布局设置」入口。
3. **Tide Grid**：统一玻璃卡片；主数据优先，次要信息降级；四张卡使用一致卡片头。
4. **Footer**：沿用现有状态栏，衔接窗口底部。

## 视觉规则

### 色彩

- 主色、强调色、状态色全部从现有主题 token 派生。
- 强调只用于焦点、主数据、选中态与关键操作。
- 玻璃层使用 `--home-panel-bg`、`--home-panel-border`，不覆盖主题对透明度的控制。

### 字体与信息层级

- 标题：现有系统无衬线中文栈，13–14px / 600。
- 页面问候：26–32px / 600–650，负字距。
- 主数据：28–36px；次级数据：11–12px。
- 英文 eyebrow 使用大写与 0.12em 字距，仅作为层级标记。

### 卡片

- 12–14px 圆角、1px 细边框、内侧高光与柔和投影。
- 卡片为纵向 flex，操作底栏通过 `margin-top:auto` 贴底。
- 卡片头统一为：28px 图标槽 + 标题/状态 + 右对齐操作。
- 拖拽柄必须是真正的 `button`，Tab 可达，Enter/Space 打开组件菜单。
- 卡片内容不因悬浮发生位移或缩放。

### 动效

- 只使用 150–220ms 的颜色、边框、阴影和透明度过渡。
- 禁止改变布局的 hover 位移 / scale。
- 遵循 `prefers-reduced-motion: reduce`。

## 交互规则

- 布局入口必须可见，右键仅作为补充，不作为唯一入口。
- 菜单打开后聚焦首个可操作项；Escape 关闭；关闭后焦点返回触发点。
- 菜单需要视口边界修正，内容超高时自身滚动。
- 组件菜单提供方向移动、列宽调整、隐藏等非拖拽替代操作。
- 键盘焦点态清晰可见；点击目标必须具备 `cursor: pointer`。

## 响应式

- 960px 窄窗口：Masthead 收窄、状态胶囊隐藏、侧栏可使用 compact 模式。
- 卡片头允许副标题省略，但不遮挡操作控件。
- 不产生横向页面滚动。
